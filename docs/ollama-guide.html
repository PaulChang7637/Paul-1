1. 重要澄清:裝在哪裡?

⚠️ Ollama 並沒有安裝在「你的電腦」上 這次的安裝發生在 Claude Code 的雲端沙箱容器裡 —— 一台暫時性的 Linux 虛擬環境。 你的個人電腦完全沒有被改動。

這代表兩件事:

  • 容器是暫時的:閒置一段時間後容器會被回收,裝好的 Ollama 與下載的模型都會消失。 因此我把「一鍵重裝腳本」scripts/ollama-up.sh 放進了 Git 倉庫, 之後任何新的沙箱階段執行一次即可還原環境。
  • 沙箱碰不到你電腦上的 Ollama:如果你想連的是自己電腦上跑的 localhost:11434,雲端容器無法直接連線。 不過倉庫裡的所有腳本在你自己的電腦上同樣可以直接使用(見第 4 節)。

2. 安裝了什麼

項目位置說明
Ollama v0.30.7(執行檔) /usr/local/bin/ollama 從官方 GitHub Releases 下載(1.39 GB 壓縮檔),已用官方 sha256 校驗碼驗證。
Ollama 函式庫 /usr/local/lib/ollama(約 2.1 GB) 推論用的執行期函式庫(含 CPU 與 GPU 後端;此沙箱無 GPU,以 CPU 推論)。
Ollama 伺服器(執行中) http://127.0.0.1:11434 以 ollama serve 於背景啟動,REST API 已驗證可連線。日誌在 /tmp/ollama-serve.log。
zstd 解壓工具 系統套件(apt) 解壓 .tar.zst 安裝包所需。

同時提交進 Git 倉庫的檔案(分支 claude/brave-thompson-cjo4c7)

檔案用途
scripts/ollama-up.sh 一鍵安裝 + 啟動腳本。可重複執行(已裝就跳過、已啟動就只回報狀態)。
ollama_client.py 零相依的 Python 客戶端(只用標準函式庫),支援 --check 連線檢查與對話。
README.md 英文版快速說明。
docs/ollama-guide.html 本說明文件。

3. 環境架構設計

☁️ Claude Code 雲端沙箱(暫時性 Linux 容器,4 CPU / 15 GB RAM,無 GPU)

📁 Git 倉庫 /home/user/Paul

  • ollama_client.py(API 客戶端)
  • scripts/ollama-up.sh(重建環境)
  • docs/ollama-guide.html(本文件)

⚙️ Ollama 伺服器

  • ollama serve @ 127.0.0.1:11434
  • REST API:/api/chat、/api/generate…
  • 模型庫:目前為空(見第 7 節)
客戶端 ⇄ 伺服器 之間走本機 HTTP(由環境變數 OLLAMA_HOST 決定位址)
▼ 對外連線(由環境「網路政策」控管)

🌐 網路政策(本沙箱目前的設定)

  • ✅ 允許 github.com、*.githubusercontent.com(因此能從 GitHub Releases 安裝)
  • ❌ 封鎖 ollama.com(官方安裝程式)
  • ❌ 封鎖 registry.ollama.ai(ollama pull 模型下載來源)
  • ❌ 封鎖 huggingface.co(GGUF 模型檔來源)

設計上的取捨

  • 改從 GitHub Releases 安裝:官方建議的 curl https://ollama.com/install.sh | sh 在此網路政策下會被擋,所以腳本直接抓 GitHub 上的官方發行檔,並比對官方 sha256 確保完整性。
  • 沿用 OLLAMA_HOST 慣例:腳本與客戶端都讀同一個環境變數(預設 127.0.0.1:11434),與 ollama CLI 行為一致 —— 同一份程式碼在沙箱、你的電腦、 或遠端伺服器上都不用改。
  • 客戶端零相依:ollama_client.py 只用 Python 標準函式庫, 不需要 pip install 任何東西,在受限環境也能直接跑。
  • 腳本可重複執行(冪等):容器是暫時的,所以把「環境」寫成程式碼放進倉庫, 而不是依賴手動安裝的狀態。

4. 之後如何使用 Ollama

情境 A:在你自己的電腦上(建議,可下載模型、速度也快)

# 1. 安裝(macOS / Windows 直接到 https://ollama.com 下載安裝程式;Linux:)
curl -fsSL https://ollama.com/install.sh | sh

# 2. 下載一個模型(llama3.2 約 2GB,qwen2.5:0.5b 約 400MB 適合低配機器)
ollama pull llama3.2

# 3. 直接在終端機對話
ollama run llama3.2

# 4. 或用本倉庫的 Python 客戶端(桌面版 Ollama 通常已自動在背景執行)
python3 ollama_client.py --check
python3 ollama_client.py "用一句話介紹你自己"

情境 B:在這個雲端沙箱裡

# 每次開新的沙箱階段,先重建環境(已裝過就只會回報狀態)
./scripts/ollama-up.sh

# 確認連線
python3 ollama_client.py --check
# → Connected to Ollama 0.30.7 at http://127.0.0.1:11434
要在沙箱裡下載模型,需先放行網域 到 Claude Code 的環境設定(Environment → Network policy)把 ollama.com 與 registry.ollama.ai 加入允許清單, 之後 ollama pull qwen2.5:0.5b 就能正常運作。 文件:code.claude.com/docs/en/claude-code-on-the-web

常用 CLI 指令速查

指令作用
ollama pull <模型>下載模型(如 llama3.2、qwen2.5:7b)
ollama run <模型>互動式對話(沒下載過會自動先 pull)
ollama list列出已安裝的模型
ollama ps查看目前載入記憶體中的模型
ollama show <模型>查看模型資訊(參數量、模板、授權)
ollama rm <模型>刪除模型釋放空間
ollama create <名稱> -f Modelfile用 Modelfile 建立自訂模型(見第 5 節)

5. 「訓練」模型:Ollama 能做與不能做的事

先講清楚:Ollama 本身是「推論引擎」,不做訓練(fine-tuning) 它負責下載、管理、執行模型。真正的微調要用其他工具完成,再把成果匯入 Ollama 使用。

路線 1|Modelfile 客製化(最簡單,不需要 GPU,幾秒鐘完成)

不改變模型權重,而是固定系統提示詞與參數,打造一個「角色化」的模型。建立檔案 Modelfile:

FROM llama3.2
PARAMETER temperature 0.7
PARAMETER num_ctx 4096
SYSTEM """你是 Paul 的專屬助理,一律使用繁體中文回答,語氣簡潔友善。"""
ollama create paul-assistant -f Modelfile
ollama run paul-assistant "幫我寫一封請假信"

路線 2|真正的微調(LoRA / QLoRA)→ 匯出 GGUF → 匯入 Ollama

適合想讓模型學會特定領域知識或語氣的情況。典型流程:

  1. 準備資料集:整理成「指令 → 回答」的 JSONL 格式,通常數百~數千筆。
  2. 用微調框架訓練(需要 GPU,可用 Google Colab 免費額度): Unsloth(最容易上手,有現成 Colab 筆記本)、 LLaMA-Factory(有網頁介面)、 Axolotl。
  3. 匯出成 GGUF 檔:Unsloth 可直接 model.save_pretrained_gguf(...), 或用 llama.cpp 的 convert_hf_to_gguf.py 轉換。
  4. 匯入 Ollama: 
    # Modelfile 直接指向你的 GGUF 檔
FROM ./my-finetuned-model.Q4_K_M.gguf
    ollama create my-model -f Modelfile
ollama run my-model

路線 3|不訓練,用 RAG(檢索增強)

如果目的是「讓模型回答我的文件內容」,通常不需要微調 —— 把文件切段、向量化存入資料庫,查詢時把相關段落塞進提示詞即可。 Ollama 內建嵌入 API(/api/embed,搭配 nomic-embed-text 等模型), 可以與 LangChain、LlamaIndex 或自寫的簡單腳本搭配。成本與難度都遠低於微調,建議先試這條路。

6. 可直接複製的範例

REST API:curl

# 單輪生成
curl http://127.0.0.1:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "為什麼天空是藍色的?",
  "stream": false
}'

# 多輪對話
curl http://127.0.0.1:11434/api/chat -d '{
  "model": "llama3.2",
  "messages": [
    {"role": "system", "content": "你是一位繁體中文助理。"},
    {"role": "user", "content": "推薦三本程式設計入門書"}
  ],
  "stream": false
}'

Python:用本倉庫的 ollama_client.py 寫一個迷你聊天機器人

from ollama_client import chat, models

model = models()[0]                      # 取第一個已安裝的模型
print(f"使用模型:{model}(輸入 exit 離開)")

while True:
    text = input("你:").strip()
    if text in ("exit", "quit"):
        break
    print("AI:", chat(text, model, system="請一律使用繁體中文回答。"))

Python:官方套件(功能更完整,支援串流)

pip install ollama
import ollama

for part in ollama.chat(
    model="llama3.2",
    messages=[{"role": "user", "content": "講一個冷笑話"}],
    stream=True,
):
    print(part["message"]["content"], end="", flush=True)

JavaScript(Node.js / 瀏覽器 fetch)

const res = await fetch("http://127.0.0.1:11434/api/chat", {
  method: "POST",
  body: JSON.stringify({
    model: "llama3.2",
    messages: [{ role: "user", content: "Hello!" }],
    stream: false,
  }),
});
const data = await res.json();
console.log(data.message.content);
